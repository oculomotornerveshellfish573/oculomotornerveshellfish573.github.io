## 🧭 Your First Pixel-Art Project

Start with a simple image. A clear subject with strong shapes is easier to read than a busy scene with many small details. Load the image into Img2Pixel and preview the pixel-art effect. Adjust the pixel size until the main shapes are visible. If the image looks too blocky, use a smaller pixel size. If it looks too detailed, use a larger pixel size.

Next, work with color. Try a smaller palette first. Check whether the important parts of the image still stand out. If they do not, add a few colors or adjust the palette. The goal is a clear image, not the largest number of colors.

When the preview looks right, save the finished pixel art. Keep the original image as well. That way you can return to Img2Pixel later and try a different pixel size or palette without starting over.
